# Qwen-Image-2.1 模型适配

官方模型卡展示文生图、单图编辑、透明图输出，并描述多参考图与局部标注／蒙版能力；这不等于任意第三方入口均提供这些控件。来源与核验日期见仓库 `docs/model-evidence.md`，缺文件时核对 Qwen 官方模型卡及当前入口文档。

1. 文生图描述目标画面与区域关系；编辑描述目标变化，同时明确保留的主体、构图和细节。输入图应走入口的图像字段，不能只把文件名写进文本。
2. 多参考图明确每张图的职责（身份、姿势、配色、风格），确认当前入口支持张数、顺序与标注方式后再给操作字段。局部修改优先确认蒙版或标注能力。
3. 透明图要明确 RGBA／透明背景目标，并确认当前部署是否输出 alpha；参数和分辨率与正文分开。
4. 官方示例既有完整句也有短描述，不能据此宣称固定长度或中文优于英文。沿用用户语言，控制逻辑和空间关系清晰即可。
5. 默认仅交付一份完整正向提示词。对文字排版任务逐字给出画内文字，并提示生成后核验可读性。

生成、编辑、多参考与透明输出的任务切换详见 [Qwen 任务表](references/tasks.md)。
