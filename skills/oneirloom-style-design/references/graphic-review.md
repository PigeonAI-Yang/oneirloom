# Review and correct a graphic result

Read only when a graphic result exists or is reported. Use the current intent and resolved adaptation. With only a user report, identify that evidence and do not claim image inspection. Diagnosis can read this file directly; it need not load the creation entry unless understanding or design must change.

## Review meaning before local compliance

Review intended meaning and subject identity first, then the whole image-and-text language, before local polish or numerical compliance. Does the subject still convey the intended action or character? Do the visible versions and directions make sense? Does the title participate in the composition with the intended hierarchy and overlap? Are accents, local interruptions, and open areas doing their intended work?

For reference transfer, compare the actual source and result at the same visual height while preserving aspect ratios. Judge the agreed adaptation, including deliberate departures. Inspect occupied contours, crop, type groups, accent bounds, seams, fragmentation, local tone changes, and readable identity together. Then check exact copy, product facts, quantities, materials, and edges at the intended viewing size. A matched bounding box or mask-coverage score cannot establish visual success.

At whole-page scale and intended viewing size, check what each join reveals and whether image coverage or deliberate gaps match the design. Check the shared paper and ink appearance, or the chosen digital finish, alongside text legibility and subject detail. A texture overlay alone does not establish the intended material relationship.

Compare the result with the actual submitted prompt or production decisions separately from reference fidelity. Use the diagnosis method to locate failures in understanding, observation, adaptation design, prompt expression, or execution only as far as evidence supports. Missing prompts or execution records leave those causes unknown. Correct asset generation does not prove a correct poster; precise assembly does not prove a sound design.

Record the decisive matches, misses, and remaining uncertainty in the same working notes. If local mechanisms match while the whole design fails, say so. Never let local compliance substitute for the whole-image verdict.

## Correct and deliver

Repair the responsible stage. An identity or meaning failure requires renewed understanding and design. A misread interruption requires renewed observation. With the design intact, fix a text or placement error in the available editable source, or use an appropriate image edit. Revise or regenerate only the content that needs it. Coordinate-only tweaks cannot fix an earlier conceptual mistake.

Continue authorized corrections without repeated approval requests. If the same critical miss survives two controlled corrections, use the diagnosis method's bounded investigation instead of adding synonymous instructions. Reuse the confirmed brief and successful work.

For a prompt-only request, return complete usable Chinese and English prompts for the selected production path. A direct-generation prompt describes the whole composition. A composite path includes its necessary asset prompts and assembly guidance. Do not force asset-only prompts or a layout plan onto every request. Keep analysis and review commentary outside copyable prompts.

For a finished graphic, deliver the final preview and state what was actually inspected and what remains unresolved. Include editable source and assets when the selected path or request warrants them. A prompt or completed queue without visual inspection is not a verified finished design.

Preserve historical prompts, images, and known metadata. Revised guidance does not inherit validation from older outputs, and one accepted example does not establish repeatability.

Keep decisive observations and remaining uncertainty in the current notes. Load result diagnosis only for a causal investigation or a persistent miss not already being diagnosed. Reuse an active diagnosis instead of reading it again. Choose another production path only when the deliverable or observed limits justify the change.
