# 摄影风格表

选一项主风格，再决定是否需要局部混合。媒介术语必须对应可见效果。

For cross-medium style exploration or a family-level request, use the [visual-family index](../../oneirloom/references/visual-families/index.md); this table remains photography-specific.

## 双向用法

- **正向写作**：按行选一项主风格，把“画面机制”列翻译成可见效果写进提示词。
- **反推识别**：反推参考图时，用“画面机制”列做识别对照——图面特征匹配哪一行，就按那一行的可见效果描述。特征对不上任何一行（混合风格、表外风格）时，不强行归类：直接按图面实际效果描述，风格名可以留未知。

| 风格 | 画面机制 | 易偏差处 |
| --- | --- | --- |
| 自然纪实 | 环境与动作同时成立；非对称瞬间、真实空间杂讯、现场光 | 把自然误作脏乱或低质 |
| 时尚抓拍 | 服装轮廓清楚、动作刚发生、表情自然、构图有张力 | 过度摆拍与硬质商业修图 |
| 棚拍商业 | 主体完整、材质一致、受控光源、背景与产品分离 | 风格词压过形状或文字 |
| 彩色胶片 | 柔亮部过渡、细颗粒、局部色偏、可辨认中间调 | 全图泛黄或灰雾遮蔽主体 |
| 电影剧照 | 具体情境、景别、视线、光向、场景深度与色彩叙事（见 [still-frame staging](still-frame-staging.md)） | 将电影感固定为青橙、高反差或浅景深 |
| 建筑摄影 | 垂直与消失线、立面层级、天气与空间尺度 | 广角变形破坏结构 |

例如“风吹头发的鲜活梦幻人像”可选时尚抓拍的瞬间动作、胶片的柔和亮部，再按区域指定天空与肤色；无需套用整份两种风格。
