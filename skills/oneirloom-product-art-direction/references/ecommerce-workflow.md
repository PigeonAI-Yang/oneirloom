# Collaborate on static ecommerce visuals

Use this reference with the product method and, for composed graphics, the existing graphic-design SOP. Keep the working brief in compact notes, not a new schema or ledger. Retain facts with their source, unknowns, creative decisions, audience, intended use, style, and the requested edit.

## Start from the available brief

For a clear request, inspect the product evidence and deliver a short design rationale plus complete prompts. Apply supplied format, copy, atmosphere, and reference roles directly. A missing minor staging preference can use a stated reasonable choice; an unknown filling cannot.

For a vague request such as “help me sell this bread,” inspect what is available before asking. Ask only questions that change the image, such as where it will be shown, whom it addresses, or whether the goal is a straightforward product view or an imaginative campaign. Do not require all three answers. Reuse answers already in the conversation. If alternatives help, offer two or three directions with different visible mechanisms and explain their purpose. For example, a breakfast table can show use context, a studio view can clarify the item, and a miniature scene can make its crust or shape memorable. These are examples, not a fixed menu. Once the user chooses, develop that direction instead of asking for another full brief.

If a missing fact blocks one proposed depiction, continue a supported alternative. An unknown filling rules out an invented cut surface; it need not prevent an intact-bread scene. If exact package wording is essential, request readable source material while continuing independent layout decisions.

## Use research only when it can help

Research can inform audience context, competing visual conventions, category composition, or a named sales placement when relevant tools are actually available. Distinguish the user's product material from external examples. Similar products never prove this item's ingredients, origin, claims, packaging, or specifications. Record external sources and separate observations from design interpretations.

If search is unavailable, continue from supplied material and state that external research was not performed. Do not invent trend, competitor, or market findings. After an authentication challenge, access denial, or rate limit, stop affected online actions. Continue independent local work and identify the evidence gap. Research is not a prerequisite for writing a useful prompt.

## Set the boundary between product and fiction

A realistic rendering describes supported exterior shape, package geometry, color, visible surface, quantity, and readable wording. Keep unknown interiors outside the depicted view. Avoid unsupported steam, bursting fillings, performance demonstrations, dimensions, and sensory or health promises that imply a product fact. An offered scene is a creative choice, not proof of how the product is used or performs.

Creative direction can transform supported properties into scenery. A chocolate ingredient confirmed for the item can supply chocolate architecture. A bread's observed oval dome can become the roof of a miniature station. The miniature people, buildings, and scale are fictional; the product identity remains recognizable. State that relationship in the outward design explanation and the prompt. Visible boundaries matter: scenery around an intact crust reads differently from a production line pumping strawberry filling into the bread.

When an ingredient is unverified, use a surface or shape mechanism, or place the requested theme in a separate clearly fictional setting. Do not make an unknown ingredient look like the product's composition or manufacture. Conversely, do not erase an agreed fantasy merely because it is physically impossible. Judge the artistic transformation against the user's intent and the factual implication against the product evidence.

If user material conflicts, identify the exact disputed property and resolve only that dependency. “Make the wrapper blue as an imagined campaign concept” permits a design transformation, not a claim that the sold item has blue packaging. “The current pack is blue; that photo is the old edition” is a user-stated correction whose provenance remains recorded. When the intended meaning is unclear, ask before presenting either version as the real item.

## Carry revisions forward

A request to change only the background preserves product facts, composition, copy, and other valid choices. A style edit changes the medium and surface treatment while preserving the current setting and factual constraints. A copy edit keeps the literal requested words; explain any necessary line break or image shift briefly. Do not use those edits to add a new ingredient or revive an earlier scene.

When the user rejects a direction, discard its affected creative choices. Retain valid product facts and any choices the new request keeps. Return a full usable prompt for every revision. Keep the reusable product and style description available for later static frames; do not initiate Live or video production.

## Separate assistant instructions from image prompts

When preparing material for use in another chat, label the collaboration brief as instructions for the assistant. That brief may explain evidence, choices, and how to continue revisions. Label the final image prompt separately. The image prompt describes the complete visible target; it does not contain research chores, internal audit questions, skill invocation syntax, or a requirement to interview the user.

For Doubao, ordinary guidance can say which supplied image to upload as product reference and which to use only for style. Keep this guidance outside copyable generation prose. Entry controls depend on actual capabilities; portable text establishes neither native Skill support nor reliable label reconstruction. Preserve the main skill's Chinese-and-English default unless the user requests a single language.

Keep prompts affirmative and concrete. Specify the actual contour, package, position, contact, and layer relationships. “Keep the product real” alone cannot prevent a different pack or invented filling. Do not export the internal error list as a long negative prompt.

## Inspect only evidence that exists

For a real result, compare the original evidence, current agreed intent, actual submitted prompt when available, and generated image. Use result diagnosis for a miss and return a complete correction. A user-reported or synthetic description supports a conditional diagnosis, not a claim of image inspection. With no result, deliver the prompt and state that generation and visual acceptance remain untested.
