# Build a wordmark identity system

## Select this recipe

Use when the exact brand name is a primary recognition cue and typography can connect the identity's applications. Preserve an approved wordmark. Use this recipe for its extension rather than redesign unless the brief includes redesign.

## Define the family

Connect the wordmark's visible lettershape character to the surrounding type through compatible weight, proportions, terminals, or contrast. Compatibility does not require the same font everywhere. Let display text carry personality while body text remains readable. Resolve Chinese and Latin names by apparent balance and the user's language priority.

Make spacing rhythm and color roles recognizable across a small header, a dense page, and the other chosen uses. An auxiliary shape may derive from a meaningful letter detail, but it must work as a repeatable graphic with clear limits. A decorative initial is not automatically the correct small-size mark.

## Adjust the content and components

Resolve the exact names, approved assets, language relationships, type character, available fonts, primary and supporting colors, and actual application formats. Choose the necessary lockups and small-size treatment from those uses. Set clear space and scale after inspecting the real mark. Do not inherit a source brand's font, dimensions, colors, or initials.

For a typography-led digital brand with no application priorities, a website header, social announcement, and presentation title can form a representative proposal. Replace this proposal when the actual context is known. Include the requested master files and a guideline book using the [delivery guide](../../references/vi-deliverables.md).

## Resolve this production brief

Replace the bracketed fields with actual decisions. Remove irrelevant components. This is a reusable system brief, not one image prompt.

```text
Create the agreed visual identity for [exact brand names and languages], used by [known audience] for [known purpose]. Preserve [approved assets and fixed choices]. The name carries recognition through [observable lettershape character]. Relate the supporting Chinese and Latin typography through [weight, proportions, hierarchy, and spacing decisions]. Use [resolved color roles and digital values] across the family.

Provide [master wordmark and necessary lockups], [monochrome and reverse versions], and [actual small-size use or variant]. Derive clear space and size guidance from the real mark and intended contexts. Extend [specific letterform relationship or other auxiliary graphic rule] into [selected applications] while preserving readable content hierarchy and a shared spacing rhythm. Use the exact supplied copy [content source] and adapt line breaks and proportions to each format.

Create the usable artwork for [application list with actual formats]. Keep the type, color roles, and auxiliary graphic behavior recognizable across different content lengths. Assemble a guideline book that explains the resolved marks, color roles, typography, graphic rules, application examples, and file uses. Deliver [actual master formats], [application source and export formats], and [manual format]. State font availability, licensing unknowns, provisional print specifications, and unverified exports separately.
```

If the user asks only for one brand board, turn the resolved appearance into a complete prompt showing the chosen wordmark variants, palette, type hierarchy, and representative applications together. Label the result a concept board. For requested generation prompts, provide complete Chinese and equivalent English versions under the main contract, with reference inputs outside the prompts. Never claim that a pictured asset is a separate delivered file.

## Inspect the result

Read every brand-name instance and inspect small-size letter recognition. Compare apparent Chinese and Latin weight, spacing, color roles, and dense versus sparse layouts. Check whether an application still belongs to the family when its headline changes. Inspect actual masters and exports independently of the presentation board; report any untested print or font assumptions.
