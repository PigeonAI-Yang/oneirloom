# Brand identity templates

Inspect the current identity assets and any selected reference family before reading its recipe. These templates describe original systems with adjustable content. They do not package another brand's assets.

| Template | Select when | Defining relations |
| --- | --- | --- |
| [Wordmark system](wordmark-system/template.md) | The name and typography carry recognition across applications | Lettershape, type hierarchy, spacing rhythm, and color roles connect the mark to everyday layouts |
| [Mascot system](mascot-system/template.md) | An approved character or a character being designed within the brief carries personality | A readable mark, expressive character, and supporting graphics share meaningful features without requiring the same detail at every size |
| [Editorial system](editorial-system/template.md) | Repeated publications, posters, social content, or web layouts need a recognizable family | Typography, content hierarchy, image finish, bounded accents, and auxiliary graphics recur across changing content and formats |

All three are researched starter recipes with no associated generated images and no tested end-to-end VI generation. Read [VI deliverables](../references/vi-deliverables.md) for scope and file requirements.
