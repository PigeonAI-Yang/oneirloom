# Icon templates

Select by the icon's use and construction. These are source-informed starter recipes with no associated image examples or production tests. An existing family and the current brief override their defaults.

| Template | Select when | Defining relations |
| --- | --- | --- |
| [Outline UI family](outline-ui/template.md) | Small functional icons need a shared line language and editable geometric forms | Comparable stroke weight, coherent caps and corners, open gaps, distinct action metaphors |
| [Solid UI family](solid-ui/template.md) | Small functional icons need filled silhouettes or must match an existing solid family | Balanced filled mass, readable counters, distinct silhouettes, native state differences when requested |
| [App symbol](app-symbol/template.md) | One app or product needs a recognizable identifier, including a requested illustrative treatment | One focused idea, fixed brand facts, small-size recognition, deliberate relation to the chosen container |
