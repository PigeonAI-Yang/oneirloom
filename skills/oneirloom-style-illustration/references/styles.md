# 绘画与插画风格表

## 双向用法

- **正向写作**：按行选一种媒介，把“优先写的可见属性”列写进提示词，用“验收”列核对表述是否可检验。
- **反推识别**：反推参考图时，用“优先写的可见属性”列做识别对照——图面特征匹配哪一行（如透明色层加纸白对应水彩），就按那一行的属性描述。特征对不上任何一行（混合画法、表外媒介）时，不强行归类：直接按图面实际笔触和色层描述，媒介名可以留未知。

| 风格 | 优先写的可见属性 | 验收 |
| --- | --- | --- |
| 水彩 | 透明色层、颜料在纸上扩散、纸白、边缘干湿变化 | 纸和水迹参与画面，而非数字模糊滤镜 |
| 油画 | 厚薄笔触、局部堆叠、色块与底层透出 | 笔触和形体有方向关系 |
| 木刻／版画 | 刀痕、套色数量、留白、印刷错位程度 | 黑白或套色逻辑一致 |
| 动画赛璐璐 | 明确轮廓、平面色块、少量分层阴影 | 人物和背景的线条系统统一 |
| 漫画分镜 | 格内景别、动作连续、视线方向、气泡与阅读顺序 | 前后格叙事可读 |
| 概念设计 | 轮廓识别、尺度参照、功能结构与世界观线索 | 即使没有微细纹理也可读主体 |

用户只说“二次元”时优先从角色比例、线条、上色和场景密度追问或依据参考图判断，不强行联想到特定作者。用户指定混合媒介时明确哪一部分由哪种媒介承担。
