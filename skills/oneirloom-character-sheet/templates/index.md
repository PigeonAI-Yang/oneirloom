# Character-sheet templates

Match the requested layout before reading a template. If none fits, use the character-sheet method to design the page. Example paths and evidence belong in each template.

| Template | Select when | Defining relations |
| --- | --- | --- |
| [Four views plus four expressions](four-plus-four/template.md) | A 2:3 card with four upper full-body views and four lower expression portraits is requested | Upper two-thirds for views; lower third for expressions; shared identity and outfit |
| [Three-view production card](three-view/template.md) | A front, side, and back turnaround is requested | Three aligned full-body panels, shared scale, eye level, outfit, and foot baseline |
| [Character wardrobe sheet](wardrobe-sheet/template.md) | One character needs several coordinated outfits, accessories, garment details, and a reusable wardrobe board; includes illustration-to-real-photography conversion | One large signature look plus five smaller outfits; a left identity/palette/turnaround rail; accessory and material studies; six matching costume portraits |
