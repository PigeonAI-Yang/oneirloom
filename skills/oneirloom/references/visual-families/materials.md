# M — Materials / 材质

**Scope.** How visible surfaces respond to light across image media.

**Choose this family when** surface response is the main unresolved style decision.

**Boundary.** The [material response reference](../../../oneirloom-color-light/references/material-response.md) owns base color, reflected illumination, finish, transmission, and scale cues. Physical units and joins belong to craft construction; drawn marks belong to illustration. Do not alter supported properties of a real product.

**Method owners.** [Color and light](../../../oneirloom-color-light/SKILL.md) owns surface response. [Craft construction](../../../oneirloom-craft-construction/SKILL.md) owns physical assembly. The selected image method owns its medium; [graphic design](../../../oneirloom-style-design/SKILL.md) owns composed layouts.

**Mechanisms and recipe.**

- [MR-01: Base color and reflected illumination](../../../oneirloom-color-light/references/material-response.md#mr-01-base-color-and-reflected-illumination), ID `MR-01`, tags `base-color`, `illumination`, and `regional-consistency`, separates supported base color from local light and reflected color.
- [MR-02: Roughness, highlights, and reflectivity](../../../oneirloom-color-light/references/material-response.md#mr-02-roughness-highlights-and-reflectivity), ID `MR-02`, tags `roughness`, `highlight-shape`, and `reflectivity`, distinguishes diffuse from polished surface appearance.
- [MR-03: Transmission, thickness, and scale](../../../oneirloom-color-light/references/material-response.md#mr-03-transmission-thickness-and-scale), ID `MR-03`, tags `transmission`, `thickness`, and `scale`, relates visible transmission and texture to edges and nearby scale cues.
- [Product surface study](../../../oneirloom-style-photography/templates/product-surface-study/template.md), ID `photo.product-surface-study`, tags M/P/T, chooses a full-product or separate close-detail photograph while keeping the supported product identity, package, base color, and light direction fixed.

**Status.** The material-response entries remain authored guidance. The product-surface full-product branch has one single-example pass. The close-detail, transparent-bag, and other surface branches remain unrun. No repeat reproduction or physical-material check is recorded.
