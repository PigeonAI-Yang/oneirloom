# C — Cinema / 影视

**Scope.** Still-image staging and photographic treatment shaped by cinematic scene, light, color, and depth.

**Choose this family when** a still image should carry a film-like visual treatment.

**Boundary.** This is still-image guidance. It does not specify video, motion, or a rendering service; a composed poster remains with graphic design.

**Method owners.** [Photography](../../../oneirloom-style-photography/SKILL.md) owns the photographic frame. Read its [still-frame staging reference](../../../oneirloom-style-photography/references/still-frame-staging.md) when the event, eyelines, action, or depth needs planning. [Graphic design](../../../oneirloom-style-design/SKILL.md) owns composed layouts.

**Still-image route.**

- [Product-use instant staging](../../../oneirloom-style-photography/references/still-frame-staging.md#product-use-instant), ID `cinema.product-use-instant`, tags C/P/T, resolves one event, contact, eyeline, frame depth, and light when a product-use moment needs film-like staging.
- [Product-use instant recipe](../../../oneirloom-style-photography/templates/product-use-instant/template.md), ID `photo.product-use-instant`, tags C/P/T, turns that choice into one still photograph of a use, receipt, or handoff instant.

**Status.** One hand-only product-use still-frame trial is not_pass. Right fingers cover the front-right sleeve, while the left support and base gap remain visible. The full-scene branch and repeat reproduction remain unrun. This does not establish motion or video capability.
