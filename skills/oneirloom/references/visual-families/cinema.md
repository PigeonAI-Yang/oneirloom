# C — Cinema / 影视

**Scope.** Still-image staging and photographic treatment shaped by cinematic scene, light, color, and depth.

**Choose this family when** a still image should carry a film-like visual treatment.

**Boundary.** This is still-image guidance. It does not specify video, motion, or a rendering service; a composed poster remains with graphic design.

**Method owners.** [Photography](../../../oneirloom-style-photography/SKILL.md) owns the photographic frame. Read its [still-frame staging reference](../../../oneirloom-style-photography/references/still-frame-staging.md) when the event, eyelines, action, or depth needs planning. [Graphic design](../../../oneirloom-style-design/SKILL.md) owns composed layouts.

**Status.** Foundation note with partial coverage. The linked reference covers static event staging and photographic light, color, and depth; it does not cover motion or video production.
