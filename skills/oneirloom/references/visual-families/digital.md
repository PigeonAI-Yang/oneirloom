# D — Digital / 数字

**Scope.** Digital-native or computational visual language in a still image.

**Choose this family when** the requested style depends on a digital or synthetic image language, not merely on the tool used.

**Boundary.** A rendered 3D appearance is not an editable 3D asset; follow the requested deliverable and existing method owner.

**Method owner.** [Digital form](../../../oneirloom-digital-form/SKILL.md) resolves geometry, volume, repeated parts, deformation, and connections. Its [form and transformation reference](../../../oneirloom-digital-form/references/form-and-transformation.md) contains the current authored mechanisms. [Color and light](../../../oneirloom-color-light/references/material-response.md) owns surface response; [graphic design](../../../oneirloom-style-design/SKILL.md) owns composed layout.

**Form routes.**

- [Anchored product deformation](../../../oneirloom-digital-form/references/form-and-transformation.md#anchored-product-deformation), ID `digital.anchored-product-deformation`, tags D/T/M/G, changes one named region while keeping selected product identity anchors readable.
- [Sculptural product variant](../../../oneirloom-digital-form/templates/product-sculptural-variant/template.md), ID `digital.product-sculptural-variant`, tags D/T/M/G, applies the mechanism to a fictional form or a specifically permitted visual change to a real product.
- The [identity-to-collectible-volume mechanism](../../../oneirloom-digital-form/references/form-and-transformation.md#identity-translated-into-collectible-volume) and [blind-box comparison template](../../../oneirloom-style-design/templates/blind-box-comparison/template.md) remain a separate person-to-figure route with its own two-panel and image-input contract.

**Status.** One corrected item-5 example is partial_not_pass. The opposite bulge is gone, but the round disc still reads as attached instead of forming a continuous lower-third swelling. The blind-box template is a separate route and does not validate product deformation. No editable 3D asset or repeat reproduction is established.
