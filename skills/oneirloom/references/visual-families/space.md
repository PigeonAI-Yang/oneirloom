# S — Space / 空间

**Scope.** Architecture, interiors, sets, and spatial arrangements as the primary image content.

**Choose this family when** spatial form or the experience of a place is the main visual concern.

**Boundary.** A visual depiction does not imply a CAD model or floor plan. Use the appropriate composition and medium capability for the requested output.

**Method owner.** [Space conception](../../../oneirloom-space-conception/SKILL.md) resolves masses, enclosure, openings, adjacency, circulation, focus, and depth. [Camera composition](../../../oneirloom-camera-composition/SKILL.md) selects the view after layout; [Photography](../../../oneirloom-style-photography/SKILL.md) owns photographic treatment. Use [graphic design](../../../oneirloom-style-design/SKILL.md) only for a composed layout.

**Product-display route.**

- [Merchant display zones](../../../oneirloom-space-conception/references/spatial-relations.md#merchant-display-zones), ID `space.merchant-display-zones`, tags S/T/G, fixes the front entrance, display island, visible route, and rear boundary before camera choice.
- [Seasonal tabletop product display](../../../oneirloom-space-conception/templates/seasonal-product-display/template.md), ID `space.seasonal-product-display`, tags S/T/G, applies those zones to a bounded tabletop while preserving supplied product and room facts.
- The recipe links to a separate [layered-paper backdrop](../../../oneirloom-craft-construction/templates/layered-paper-backdrop/template.md), ID `craft.layered-paper-backdrop`, tags M/R/T, only when cut-paper construction is part of the setting.

**Status.** One corrected item-3 display example is partial_not_pass. The entrance joins a dark trench or level break, so the same-tabletop route remains unpassed. No measured plan, CAD model, or spatial feasibility is established. Other branches and repeat reproduction remain unrun.
