# P — Photography / 摄影

**Scope.** Image treatment based on photographic framing, light, depth, and capture character.

**Choose this family when** the requested look is defined by photographic rendering.

**Boundary.** Photography describes a method, not the subject or layout; fashion, product, or cinematic content still follows its requested deliverable owner.

**Method owner.** [Photography](../../../oneirloom-style-photography/SKILL.md). Use the [still-frame staging reference](../../../oneirloom-style-photography/references/still-frame-staging.md) only when an event or scene relationship needs explicit planning.

**Recipe routes.**

- [Product surface study](../../../oneirloom-style-photography/templates/product-surface-study/template.md), ID `photo.product-surface-study`, tags M/P/T, resolves a full-product view or a separate close-detail view with the same supported product and light choices.
- [Product-use instant](../../../oneirloom-style-photography/templates/product-use-instant/template.md), ID `photo.product-use-instant`, tags C/P/T, shows one person using, receiving, or handing over a product in one still frame.
- Use the [photography template index](../../../oneirloom-style-photography/templates/index.md) only when an existing pose or scene recipe matches the request.

**Status.** The linked product-surface full-product branch has one single-example pass. The product-use hand-only branch is not_pass because fingers cover the front-right sleeve. The full-scene branch and repeat reproduction remain unrun. The four-pose record is historical evidence only.
