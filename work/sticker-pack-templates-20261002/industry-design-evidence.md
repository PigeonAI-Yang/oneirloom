## 1. LINE: communication categories and official illustrated guidance

- Source: [LINE Sticker Expression Guide](https://lineforbusiness.com/files/en_LINE%20Sticker%20Expression%20Guide_2018.pdf), official LINE for Business PDF, 12 pages. Filename indicates 2018; its example recommendations explicitly use data collected as of March 2017.
- Read: PDF body, especially pages 2 and 8 (one-based). Screenshot request for page 8 returned a reference but no visible pixels.
- Concrete reusable content: the guide separates everyday conversation phrases, emotional responses, and situations/actions. Example phrase inventory includes hello, thanks, I love you, okay, and sorry; emotion examples include happiness, sadness, anger, and delight. It recommends a meaningful first frame for animated sticker previews, outlines, and removing unused space to improve chat display size.
- Status: phrase/emotion choices are recommendations. Some restrictions are specifically for sponsored stickers; this historical document must not become a universal current Creators Market rule. It is a readable PDF guide, not a verified editable art template.
- Reuse: use the documented communication categories to audit a pack's coverage. No license to copy the illustrated character artwork was identified.

## 2. Tencent ISUX: character consistency package and expression library

- Source: [PUPU Aliens](https://isux.tencent.com/articles/pupu-aliens), Tencent ISUX original IP case, 2020 according to the Primary's source reading.
- Read: article body read by the Primary and supplied to this research assignment. No pixels inspected.
- Concrete resources described: six-view shapes; Character Basic Shape with stroke and non-stroke versions; Group Pose, Individual Pose, and Facial Expression graphic libraries; and a 3D Action Guide. The process selects both common expressions and character-specific expressions, then discusses storyboards. Motion problems can require returning to rigging while preserving the basic model.
- Status: evidence of one professional team's actual design system, not a rule that every chat-sticker project requires six views or 3D production.
- Reuse: reference the structure of an identity package plus separate pose/expression libraries. This supplies stronger evidence for consistency planning than an invented emotion preset. No downloadable production files or reuse license were confirmed.

## 3. Tencent ISUX: a real 16-action daily-life pack

- Source: [PUPU 3D Sticker: Daily Life](https://isux.tencent.com/articles/pupu3Dsticker-dailylife.html), original Tencent ISUX production case, 2019-06-26.
- Read: article body read by the Primary and supplied to this assignment. No pixels inspected.
- Concrete production evidence: a 16-action everyday-life series; poses constrained by a round body without a neck or legs; stepped key-pose previsualization before animation; and online-file optimization later in production.
- Status: an actual pack and production sequence. The full list of 16 actions was not extracted from visible images and must not be fabricated.
- Reuse: determine a pack's communicative actions before full production, then prove that the character's anatomy supports those actions. This is a workflow example, not a downloadable 16-slot template or an industry-wide action list. No artwork reuse license confirmed.

## 4. Okayama / CELSYS: reusable canvas, margin, file, and export setup

- Source: [Part 1. Let's Create a LINE Sticker With Clip Studio Paint](https://tips.clip-studio.com/en-us/articles/1579), illustrator Okayama's tutorial published by ClipStudioOfficial. Publication date not established.
- Read: article body, sections 1.2–1.4. Image links present; pixels not viewed.
- Concrete template mechanism: register a canvas preset; create a masked layer folder to protect the margin; scale both canvas and mask proportionally if working larger; register repeated export settings as an Auto Action. This is an explained method, not a supplied downloadable template.
- Concrete file organization: number individual sticker files sequentially, use main.png for the pack's main image and tab.png for the chat thumbnail, then put the deliverables together in a ZIP. The main image should represent the product; the thumbnail should make its theme recognizable.
- Status: creator workflow recommendations. Historical numerical submission requirements in this tutorial are not the current authority; use current platform guidance from the other research task.
- Reuse: follow the setup and packaging method with original art. No license to redistribute the tutorial's illustrations was identified.

## 5. UTK: an actual downloadable eight-slot authoring template

- Source: [8 template slots for LINE stickers](https://assets.clip-studio.com/en-us/detail?id=2232417), original uploader UTK, CLIP STUDIO ASSETS content ID 2232417. Page displays relative publication dates; no reliable absolute date established.
- Read: listing body and output instructions. Linked PNG returned binary-like text through web extraction, not a rendered preview; grid rows/columns remain unverified.
- Confirmed listing: Free; Download; Layer template; CLIP STUDIO PAINT PRO/EX. It explicitly describes eight slots, a masked Drawing folder, draft layers excluded from export, and saved selections required for output. Export is selection-based after layer merging. A corresponding Auto Action is linked as content ID 2232423, but was not opened or validated.
- Status: downloadable availability is confirmed by the listing; acquisition, import compatibility, exact canvas geometry, and exported files were not tested. No PSD or generic PNG template format was asserted.
- Reuse: users can obtain it through the original ASSETS entry for their own drawing workflow. Material redistribution is restricted by the official usage guidance below; do not bundle it in a skill.

## 6. CELSYS: rights applying to the ASSETS template

- Source: [What are the rules for using materials from ASSETS?](https://support.clip-studio.com/en-us/faq/articles/20190003), official CELSYS support. Publication/update date not established.
- Read: full relevant FAQ body; no visual evidence needed.
- Confirmed policy: ASSETS materials can be used for commercial and noncommercial artwork and can be customized. Materials marked as licensed have specific terms that must be followed. Editing does not transfer ownership to the user. Downloaded materials cannot be given or sold to other users. Creator contact and attribution are not generally required by this FAQ.
- Practical boundary: linking the eight-slot template is supported; packaging the downloaded source material for redistribution is not. Artwork made using a template and redistribution of the template itself are different uses.

## 7. Mirekurage: explicit expression/action decomposition

- Source: [Let's create expressive LINE stickers!](https://tips.clip-studio.com/en-us/articles/11288), original tutorial by mirekurage; machine-translated English. MonthlyTIPS202510 tag indicates context, not a verified publication date.
- Read: article body, especially sections 2.2–2.3; image examples not visually inspected.
- Concrete design map: communicative intent is coordinated across face, hands, body, and props, optionally effects. For celebration, it describes joyful facial expression, hands offering something, a forward-leaning body, and celebration props. Alternatives include clapping, pulling a party popper, hugging, and gifts/bouquets. It recommends grouping rough concepts by emotion before final drawing, with clear silhouettes, readable lines, and simplified shading.
- Status: creator advice and a worked semantic-to-pose example, not a mandatory or downloadable inventory. The body contradicts itself on dimensions and gives a suspect pack-count claim; do not use it for platform requirements.
- Reuse: translate a desired chat function into coordinated visual components. No license to reuse example character art or downloadable planning worksheet was confirmed.

## 8. EllyBonBon: a small expression set and layered production process

- Source: [Make Stickers and Stamps with Clip Studio Paint! Video+Text](https://tips.clip-studio.com/en-us/articles/3052), original tutorial by EllyBonBon / Ondine. MonthlyTIPS202004 tag is present; exact publication date not established.
- Read: article body. Video and illustrative pixels not inspected.
- Concrete inventory: five starting emotions—happy, angry, sad, shy, and love—and an explicit choice of face-only or half-body framing. Workflow: sketch, vector ink, separate color-component layers, simple shading, merge a copy while preserving editable layers, add a border, resize if needed, and export transparent PNG. The creator explicitly frames this as Telegram/WhatsApp chat-sticker production; the later print-color aside is not treated as chat-sticker specification.
- Status: original creator recommendation, not a platform-mandated five-item pack. No downloadable source pack or worksheet confirmed.
- Reuse: a small verified example inventory and production sequence. Use current platform specifications rather than treating this tutorial's app-related statements as current rules. No illustration reuse license confirmed.

## 9. LINE: real reusable caption-style files

- Source: [How to Make Custom Stickers](https://creator.line.me/en/guideline/customsticker/detail/), official LINE Creators Market. Publication/update date not established.
- Read: full relevant article body; no screenshot pixels inspected.
- Concrete reusable artifact: custom-{sticker_id}.style imports/exports caption placement, font, and related settings across custom-sticker sets. The editor also applies a style to all stickers and previews the whole set. It requires designing space for the caption; a sticker supports one custom caption. Four to six characters is a recommendation, not an absolute rule.
- Status: confirmed official tool capability, specific to customizable-caption stickers. It is neither a character/action preset nor a general PSD pack template. Export/import was not executed.
- Reuse: use the platform's style-file mechanism when this sticker type is selected; test maximum caption lengths and language-specific rendering. No right to copy somebody else's sticker artwork follows from this mechanism.
