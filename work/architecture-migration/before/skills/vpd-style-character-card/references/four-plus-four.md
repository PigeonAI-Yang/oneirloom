# Four-view plus four-expression character-card template

Use this format when the user requests the matching 2:3 fashion character board: four full-body angles in the upper two-thirds and four expression close-ups in the lower third. Keep the fixed layout and labels. Fill adjustable slots from user-provided settings, traits visible in the reference, or applicable router defaults. For an unspecified young beauty subject, use the router's 25-year-old adult generation target; do not claim a photographed person's age is proven by appearance. The 45-degree prop sentence is optional and is removed in full when no prop is specified or visible.

## Positive prompt template

```text

画面上方约占整页三分之二，分为四列等宽全身视角，人物头顶、双手、双腿与鞋履完整入画，四格人物比例一致，脚下落在同一水平基线上。四格自左向右分别为正面自然站姿、面向镜头的45度斜侧站姿、左侧面站姿、背面自然站姿；各视角保持同一角色身高比例、发型、服装与影棚光线。45度视角格中，角色手持[仅在用户指定或参考图可见时填写的专属道具及外观]；该道具只出现在此格，其他三格以自然垂手的姿态呈现。上排各格顶部清晰标注“正面 Front”“45度 45° View”“侧面 Side”“背面 Back”。

使用整齐的细分隔线分开八个面板，标签排版清楚、对齐一致，背景、色调、照明和角色细节在八格之间连贯统一，呈现完成度高的角色视觉设定页。
```
