# Three-view production-card template

Use this format for a compact character turnaround intended for production reference. It presents one consistent character in front, side, and back views. Fill identity and design slots from the user's settings or visible reference facts. Use user-supplied back-view details when a reference does not show them.

## Positive prompt template

```text
请制作一张[用户指定画幅比例，未指定时采用横向画布]的角色三视图生产设定卡，使用[用户指定的媒介与风格]、简洁的浅[背景色]背景、均匀柔和的照明与清楚的轮廓呈现。主体为同一位[角色年龄阶段与外观设定，按用户指令填写]：[面部、发型、体态、肤色或其他已确定的身份特征]。角色穿着[完整基础服装的结构、颜色、材质与配件，按用户设定或参考图可见事实填写]，发型、服装、比例与配色在三个视角中保持一致。

整页横向排列三个等宽的全身视角面板，按从左到右的顺序展示正面、左侧面与背面。三格采用一致的角色高度、镜头距离、视平线和脚底基线，角色以稳定、中性的站姿呈现，双臂自然垂放并与躯干保持适当间距，使身体和基础服装轮廓清晰可读。正面格展示[正面可见的面部、服装与配件细节]；侧面格展示[用户已设定或参考图可见的侧面轮廓与结构]；背面格展示[用户提供的背面发型、服装结构与配件信息]。

以细分隔线划分面板，并在各格顶部清晰标注“正面 FRONT”“侧面 SIDE”“背面 BACK”。背景与照明保持统一，画面留白均匀，三视图具有简洁、清晰、便于绘制与制作对照的角色生产设定卡质感。
```
