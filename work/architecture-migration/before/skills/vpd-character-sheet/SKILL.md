# 角色设定板

## 适用范围

当用户要设计角色设定板、角色一致性卡或 IP 形象档案时加载本技能。它负责角色跨视角的身份连续性和整页信息层级。需要参考图时，同时加载 `vpd-visual-analysis` 来提取可见事实；按需加载表现形式、构图、光色和指定模型分支。

用户只想分析或复现一张图中的人物外观时，使用 `vpd-visual-analysis`，不要把普通反推扩展成设定板任务。

## 整理角色依据

先在工作过程中分开记录三类依据：用户明确指定的设定、参考图直接可见的特征、为填补设计空白而作的推断。参考图没有显示的部位不能写成已观察事实。不要把推断升级为角色背景或身份设定，除非用户要求创作这些内容。

从上述依据中选出少量稳定身份锚点，例如轮廓比例、面部结构、发型特征、主色分区或具有辨识度的服饰配件。只选能帮助识别角色的细节；不要仅凭职业或一件配饰推定额外道具并把它固定为身份标志。给同一角色安排多个视角时，保持这些锚点一致，并让姿势、表情和视角只改变它们应当改变的部分。对参考图中不可见的结构，按用户目标作必要推断，并在推断会影响身份时单独标明。

## 组织版面

让主形象先建立角色印象，并明显高于辅助信息。需要比较形体时，先用自然站姿作为基准，再按用途选择正面、侧面、背面或斜侧视角；各结构视角保持同一基础服装，服装变体另列。需要表现角色状态时，再选择情绪表情、微表情、头部转动、姿势、手势或情绪近景。建模、绘制、动画、品牌展示等用途需要的信息不同；不要强行加入一套固定视角或把所有细节挤进一页。

需要解释辨识度时，可加入剪影、色板、发型分层、服装材质、配饰或鞋履细节。名称、年龄、性格线索与主题说明只在用户提供或要求创作、且确实有助于使用设定板时加入。控制面板数量、大小、间距和标签层级，使辅助项服务于角色主体，不与主形象争夺注意力；若标签文字必须准确，优先在可编辑排版环节完成。

## 组织提示词与工具输入

按主技能的输出契约给出完整、可复制的正向提示词。明确人物身份锚点、主形象的版面优先级、所需视角或细节面板，以及贯穿全页的画风和色彩关系。用目标状态描述画面，不在正向提示词里加入排除句或负面词。

将参考图、模型参数、画布比例、蒙版或分轮生成步骤放在提示词正文之外。只有在指定模型和入口支持相应输入时，才建议把参考图用于身份参考或拆分生成步骤；需要确认模型能力时加载对应模型子技能。模型未指定时，给出可移植的自然语言建议，不编造参数。

纯文本提示词不能保证多个视角的人物完全一致。若用户要求严格一致，说明需要使用当前入口支持的角色参考、图像编辑或迭代控制，并把这类建议与提示词分开。默认只交付用户所需的完整提示词；仅在用户需要确认依据，或关键推断会改变角色时，才简短列出依据与未确定项。
