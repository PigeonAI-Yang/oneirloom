# 绘画与插画风格表

| 风格 | 优先写的可见属性 | 验收 |
| --- | --- | --- |
| 水彩 | 透明色层、颜料在纸上扩散、纸白、边缘干湿变化 | 纸和水迹参与画面，而非数字模糊滤镜 |
| 油画 | 厚薄笔触、局部堆叠、色块与底层透出 | 笔触和形体有方向关系 |
| 木刻／版画 | 刀痕、套色数量、留白、印刷错位程度 | 黑白或套色逻辑一致 |
| 动画赛璐璐 | 明确轮廓、平面色块、少量分层阴影 | 人物和背景的线条系统统一 |
| 漫画分镜 | 格内景别、动作连续、视线方向、气泡与阅读顺序 | 前后格叙事可读 |
| 概念设计 | 轮廓识别、尺度参照、功能结构与世界观线索 | 即使没有微细纹理也可读主体 |
| [Decorative rainy-night print illustration](decorative-rainy-night.md) | Layered curled foliage, near-black edge framing, luminous depth corridor, crisp fine outlines, flat limited-color print-like shapes, light paper grain | Environment remains dominant and figures stay small; linework and color logic stay coherent. Load only when explicitly requested or when a reference combines ornate foliage with an environment-led print-like scene; rain or teal alone is not a trigger. |

用户只说“二次元”时优先从角色比例、线条、上色和场景密度追问或依据参考图判断，不强行联想到特定作者。用户指定混合媒介时明确哪一部分由哪种媒介承担。
