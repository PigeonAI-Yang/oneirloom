# 插画与绘画表现

先确定媒介和图像结构，再确定线条／边缘、笔触／肌理、色层、纸或画布参与方式、主体与背景的关系。同名风格可能有多种技术实现；描述实际可见效果。

例：水彩街角可写“铅笔浅线界定建筑，透明色层在湿润纸面上轻微扩散，窗沿保留纸白”。漫画分镜优先角色视线、动作方向、画幅连续性与格间叙事。概念设计优先形状语言、尺度参照与氛围。仅当明确需要混合媒介时引入摄影成像术语。

按具体媒介读取 [绘画风格表](references/styles.md)。
