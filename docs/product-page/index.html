06一套可以继续对话的创作方法

说出想法。看见结果。
继续把画面改对。

01 / 想法

给目标与材料

一句需求、参考图，
或已有提示词与结果。

02 / 构思

明确画面关系

主体、位置、姿态，
构图、光色与风格。

03 / 提示词

交付完整版本

默认中英双语，
按目标模型适配。

04 / 修改

对照结果继续改

找到主要偏差，
给出完整修订稿。
