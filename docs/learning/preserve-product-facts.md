# 改背景时保留商品事实

当你只想换背景时，把“背景”写成唯一要改变的维度，并带上当前完整提示词或可确认的当前任务。Oneirloom 的共享约定会沿用仍有效的商品事实与画面选择；如果没有当前目标，不要让助手猜哪一版需要修改。

下面继续使用[第一项商品任务](first-product-task.md)的虚构文字资料。商品事实是一只直立奶油白外带饮品杯、贴合闭合的白色杯盖、浅灰色空白杯套、浅木色台面。画面比例为 4:5，机位正对杯身中部并略高于杯身中线，左侧柔光，暖中性色调，原背景为浅米白。现在只把背景改为浅绿色。

## 发给 Oneirloom 的改稿请求

```text
请读取当前对话中的完整商品任务与共享交互约定。只把浅米白背景改为浅绿色。保留一只直立的奶油白外带饮品杯、贴合并闭合的白色杯盖、浅灰色空白杯套、浅木色台面、4:5 竖版、原有机位、左侧柔光和暖中性色调。不要改商品、数量、摆位、摄影风格或其他已确认选择。请用中文返回完整改稿提示词，不要只给替换片段。
```

## 完整改稿提示词

这是可直接交给图像工具的完整中文提示词。它只把背景换成浅绿色，保留商品与已有画面选择。

```text
4:5 竖版暖中性色调的静物商品摄影。一只直立的奶油白色外带饮品杯放在浅木色台面上，杯口配一只贴合并闭合的白色杯盖，杯身套一圈浅灰色空白杯套。杯子完整入镜。镜头正对杯身中部并略高于杯身中线。浅绿色背景，左侧柔光照亮杯子。
```

如果背景变化必然要求调整接触阴影或反光，说明那项必要的联动，再给出完整提示词。其他商品事实仍以原始资料为准；本例没有提供品牌、饮品内容或容量，不需要为了换背景补充这些信息。
