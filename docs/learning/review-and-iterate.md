# 复核结果并只改偏差

先把完整提交提示词、原始商品资料和实际生成结果放在一起。若你只是在文字中描述了图片，就明确标为“用户描述”；没有看到图片时，不要写成已检查图像。结果诊断方法负责完整的证据比较和归因，本篇只给一个短例子，详细步骤见[结果诊断方法](../../skills/oneirloom-result-diagnosis/SKILL.md)。

以下是作者编写的模拟案例，不是已经生成或检查的图像。它沿用[第一项商品任务](first-product-task.md)中的杯子；在这个模拟分支中，用户另提供的商品参考图明确显示低矮平顶白盖，实际提交的提示词也写明了这一形状。模拟偏差描述为“杯盖变成拱起的圆顶”。如果你手上的素材没有显示盖体轮廓，盖体形状应标为未知，不能直接判定圆顶是错误。

| 检查项 | 状态 | 本例记录 |
| --- | --- | --- |
| 颜色 | 通过 | 用户描述中杯身仍为奶油白、杯盖仍为白色、杯套仍为浅灰。 |
| 形状 | 失败 | 在本模拟输入确认的低矮平顶轮廓，结果描述为拱起圆顶。 |
| 结构 | 通过 | 模拟描述仍是一个直立杯，闭合杯盖贴合杯口。 |
| 包装与数量 | 通过 | 仍是一只杯子，浅灰色杯套位置与输入相同。 |
| 文字 | 不适用 | 当前任务没有要求商品图中出现文字。 |
| 标记 | 不适用 | 当前资料没有要求呈现品牌标识。 |

在这个模拟分支里，平顶形状已经由来源图和已提交提示词明确，因此它是图像结果相对提示词的偏差。若完整提示词漏写了来源图中可确认的形状，先修正提示词遗漏；若来源本身无法确认，保留“未知”，不要把生成图当作商品的新规格。

## 只修正杯盖的完整提示词

下面的改稿只适用于来源素材确实确认低矮平顶杯盖的任务。杯子数量、杯身、杯套、背景、机位和左侧柔光都沿用原选择。

```text
4:5 竖版暖中性色调的静物商品摄影。一只直立的奶油白色外带饮品杯完整地放在浅木色台面中央，杯身套一圈浅灰色空白杯套。杯口配一只低矮平顶的白色杯盖，盖缘贴合杯口并保持闭合。镜头正对杯身中部并略高于杯身中线，杯身保持竖直。浅米白背景，左侧柔光照亮杯壁和杯盖，杯子下方的台面上形成柔和接触阴影；整体保留简洁、温暖的静物摄影质感。
```

真实任务中，把原始商品资料、实际提交的完整提示词和图像结果一并交给诊断方法。复核后，保留已确认的商品事实，并把完整修订提示词交回你实际选用的图像工具执行。
