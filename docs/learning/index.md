# Oneirloom 免费学习路径

按你现在要完成的事，选择对应路径。你可以从安装、首项商品任务或已经开始的修改直接进入。

| 你现在的情况 | 这篇会帮你完成什么 |
| --- | --- |
| 想在一个 Codex 项目里安装已发布的固定包 | [安装固定发布包](install-fixed-package.md)，核对 ZIP、版本清单并在新聊天确认项目技能路径。 |
| 已经打开安装好的项目，准备第一次做商品图 | [完成第一项商品任务](first-product-task.md)，把商品事实、未知信息和画面选择写进一段可直接发送的中文任务说明。 |
| 已有完整提示词，只想改背景 | [改背景时保留商品事实](preserve-product-facts.md)，只更新背景，并拿到完整的新提示词。 |
| 已有真实结果并发现某个商品细节变了 | [复核结果并只改偏差](review-and-iterate.md)，分清已确认偏差与未知项，再修正本轮提示词。 |
