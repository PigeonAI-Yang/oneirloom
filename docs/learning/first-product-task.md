# 完成第一项商品任务

把清楚的商品任务交给已安装的 Oneirloom 方法，取得完整提示词，再用你本次选用的图像工具执行并查看结果。

先在安装了固定包的项目中开一个新聊天，确认宿主发现了项目内的方法。若你上传素材，为每份素材起一个别名并写清用途，例如“商品照 A 说明外观和包装”“风格参考 B 只参考光色”；不要让风格图充当商品事实。本例不含图片，下面的商品资料全部是为教学设定的虚构文字输入。

## 本例的资料分栏

**本例确认的商品事实，均来自文字描述。** 一只直立的奶油白色外带饮品杯，杯口配有贴合并闭合的白色杯盖，杯身套一圈浅灰色空白杯套，放在浅木色台面上。

**本例选择的画面表达。** 用途是电商商品页首图，4:5 竖版，暖中性色调的静物摄影，浅米白背景，左侧柔光；镜头正对杯身中部、略高于杯身中线，完整展示杯子。

**本例仍未知的内容。** 品牌、商品名、杯内饮品、配料、容量、尺寸、杯身材质和未提供的包装文字都没有资料。

## 发给已安装方法的完整任务说明

下面这段是交给已安装方法的任务指令，不是图像提示词。把整段发给新聊天中的已安装方法。若这次使用英文或其他语言，把最后一项语言要求改成你希望收到的语言；不要留空字段。

```text
请先读取我当前 Codex 项目中已安装的 oneirloom-product-art-direction 方法及它引用的共享交互约定，再处理这项任务。请只用中文回复。

目标：为电商商品页首图准备一张能看清商品外观的静物商品图提示词。
渠道与比例：电商商品页首图，4:5 竖版。
素材别名：A 是以下文字商品资料，不是照片；本次没有上传图片。
商品事实：画面中一只直立的奶油白色外带饮品杯，杯口配有贴合并闭合的白色杯盖，杯身套一圈浅灰色空白杯套，杯子放在浅木色台面上。这些是用户提供的文字描述，不是对图片的观察。
画面选择：暖中性色调的静物摄影；浅米白背景；左侧柔光；镜头正对杯身中部、略高于杯身中线，杯子完整入镜。
未知内容：品牌、商品名、杯内饮品、配料、容量、尺寸、杯身材质及未提供的包装文字。
请先给简短的构图说明，再给一段完整、可直接用于图像工具的中文提示词。把文字事实与画面选择分开；不需要先填问卷。完成提示词后，我会在自己本次选用的图像工具中运行它，并把真实结果拿回来复核。
```

## 作者编写的完整图像提示词示范

下面这段与助手任务指令分开，描述可以直接交给图像工具的画面。

```text
4:5 竖版暖中性色调的静物商品摄影。一只直立的奶油白色外带饮品杯放在浅木色台面上，杯口配一只贴合并闭合的白色杯盖，杯身套一圈浅灰色空白杯套。杯子完整入镜。镜头正对杯身中部并略高于杯身中线。浅米白背景，左侧柔光照亮杯子。
```

拿到已安装方法返回的提示词后，在你选用的图像工具中运行。复核结果时，对照杯子数量、杯盖与杯套、摆位、背景、机位和光线，并记录实际使用的完整提示词、工具、模型与设置。
