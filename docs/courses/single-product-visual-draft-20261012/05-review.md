# 05 用六个样本学习检查结果

这一课的目标是写出有依据的结果检查表。不要只问“好不好看”。先核对商品和关键关系，再判断这张图是否适合当前用途。

## 将三个东西放在一起

检查时同时保留原始资料、实际提交的完整提示词和真实结果。资料告诉你商品应是什么样；提示词告诉你本轮明确要求了什么；结果告诉你实际出现了什么。

如果你只有别人对图像的文字描述，就把依据写为“结果描述”，而不是“我看到了”。本课使用现有六样本的检查记录做阅读练习，不要求你重新生成这些图。

## 六个样本分别教会我们什么

| 方法与样本 | 已有单次检查结果 | 学习重点 |
| --- | --- | --- |
| 商品表面摄影：奶油白包装 | 通过：完整包装、青绿色条纹、珊瑚色圆点、空白标签和左侧光线可见 | 把完整轮廓与图形逐项检查，不只评价颜色好看 |
| 商品使用瞬间：手持杯子 | 未通过：右手手指仍遮住杯套正面右侧；底部支撑与间隙可见 | 支撑成立不代表关键商品面已经露出 |
| 季节桌面展示 | 部分未通过：入口和右侧空道扩大，但入口接到暗沟槽或高差 | 有空道不代表路线在同一桌面上连续 |
| 分层纸景与罐体 | 通过：白色纸舌或纸桥支撑抬起的纸片，层次与底部接触可见；背板顶部被裁切 | 支撑连接和商品完整度可以分别检查，裁切也要记录 |
| 虚构容器形态 | 部分未通过：多余凸起去除，右侧圆片仍像附加部件 | 形状数量正确不代表连续膨出的机制成立 |
| 单品上衣 | 通过：短拉链止于上胸，下方衣身连续到完整下摆 | 关键细节要明确到起止位置，不能只写“有拉链” |

这些记录保留三个通过、两个部分未通过和一个未通过的结果。通过项说明本次具体检查观察到了什么；它不自动给下一次生成赋予相同结论。样本来源与原图、修正图的区分见[检查记录](../../../work/product-expansion-20261011/visual-inspection-corrections-round1.md)。

## 先描述现象，再判断来源

对于手持杯子，先写“手指遮住杯套正面右侧”，不要直接写“模型不懂手”。前者是可见问题，可以与任务目标比较；后者是没有证据的原因推断。

继续问三个问题：原始资料是否确认了需要展示的商品面？提示词是否把露出这个面写清？图像是否仍出现遮挡？如果提示词漏写要求，先补提示词。如果提示词写清而结果仍遮挡，再处理该结果偏差。如果来源根本不清楚，先补来源。

## 杯子检查表怎么填

在你自己的结果上依次检查数量与完整轮廓、杯盖和杯套、基色、接触支撑、机位、背景与光线。给每项写“通过、未通过、未知或不适用”，再补一句依据。

| 项目 | 可用依据 | 对应判断 |
| --- | --- | --- |
| 数量 | 结果中杯子数量与资料比较 | 一只还是多只 |
| 杯盖闭合 | 杯口与盖缘的关系 | 闭合贴合，还是出现缝隙 |
| 杯套 | 颜色、位置和文字 | 灰色空白面是否保留 |
| 杯盖顶面形状 | 当前文字资料没有指定 | 保持未知，不能凭偏好判错 |
| 支撑 | 杯底与台面的接触 | 是否悬空或阴影脱离 |
| 当前用途 | 完整商品是否易于辨认 | 能否作为这次首图候选 |

## 练习与参考答案

把“桌面空道很大，所以路线检查通过”改成合格的检查结论。

参考答案：“右侧空道宽，但入口接到暗沟槽或高差，无法清楚确认同一桌面上的连续路线；该项部分未通过。下一轮先处理入口与路线的连续关系，再调整视点。”这句话将可见改善和剩余问题一起保留，不会把一个局部通过扩展成整体通过。

再把“杯盖不好看”改为可执行描述。如果来源确认了低矮平顶，而结果变成拱起圆顶，可以写出这一差异。若来源没确认顶面形状，则只记录当前外观，提出审美选择，不能冒充事实错误。

## 本课完成条件

提交一张至少覆盖商品身份、部件、包装、支撑和本次用途的检查表。每个未通过项写出具体差异，每个未知项说明缺少哪份依据。下一轮只选一个最影响当前目标的问题处理。
