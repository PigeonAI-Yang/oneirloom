# 03 按关系选方法，而不只选风格

这一课要完成一个小决策：这张图主要靠什么关系成立？风格词可以说明感觉，方法则告诉你该安排什么、检查什么。

## 把“想要什么感觉”变成画面机制

对于杯子商品页首图，首要问题是外形和包装能否看清。选择静物商品摄影，以完整全貌为主视图，让杯盖、杯套和杯身轮廓清楚分离。背景与光线服务于这件事。

如果改成“一个人将杯子递给另一个人”，首要问题变成手和商品的接触、支撑与遮挡。仅写“电影感”无法说明手指怎样放置，也无法让杯套正面自动露出来。

再比如，商品摆在季节展示桌上，关键是入口、路线、展示岛与背板的相对位置。它首先是空间关系，然后才是拍摄角度。

## 六种已整理的方法怎样选

下面的选法来自现有配方与样本记录。选择一个符合当前目标的主方法，不需要把六种效果堆进一张图。

| 当前任务 | 主方法 | 优先检查 |
| --- | --- | --- |
| 看清完整商品和表面外观 | 商品表面摄影 | 轮廓、包装、基色、亮区和接触阴影 |
| 展示人使用或交接商品的一瞬间 | 商品使用瞬间 | 手部支撑、可见间隙和正面遮挡 |
| 展示桌面上的季节陈列 | 空间布局 | 入口、同一桌面上的连续路线、商品尺度 |
| 用分层纸景衬托商品 | 工艺构造 | 层片、支撑连接、底部接触和商品完整度 |
| 为虚构容器探索形态 | 数字形态 | 膨出从主体何处开始、怎样连续接回 |
| 推广一件服装 | 单品服装展示 | 领口、袖子、拉链长度和完整下摆 |

形态探索适用于明确的虚构概念。若商品是现有杯子，不能因为想做艺术效果就替它增加一个凸起。先问自己是在展示现有商品，还是设计新概念。

## 给杯子写一段构图说明

贯穿练习仍是文字设定。可以这样决定画面：

“用一张 4:5 竖幅静物摄影完整展示杯子。杯子位于浅木台面中央，画面留出杯盖上方和杯底下方的边缘空间。相机正对杯身中部，略高于杯身中线，避免极端俯拍压缩外形。浅米白背景与奶油白杯身通过明暗差分开。左侧柔光照亮杯身，接触阴影贴合杯底。”

这段说明已经包含可检查的关系。你可以判断杯子是否完整、机位是否偏高、轮廓是否融入背景。它不依赖“大片感”“高级质感”等难以单独核对的词。

## 练习与参考答案

客户说：“想让人一眼看清杯套上的图形，画面里最好有人拿着。”你该先问哪一项？

先确认图形的可读来源与完整露出的要求，再安排拿杯方式。构图中让一只手从有支撑的位置握持杯身，手指避开需要展示的杯套正面。若当前入口无法稳定保留图形，先说明实际可用操作并让用户选择；不要在没有结果时保证图形一定准确。

这里的检查重点是“支撑成立且图形可见”。“人物微笑、咖啡馆氛围、金色阳光”可以作为之后的选择，却不能解决这个核心关系。

## 本课完成条件

用一句话写出你的主方法，再写三条可检查的关系。杯子练习可以交“静物商品摄影；完整轮廓、杯底接触、左侧光线”。如果选了人物使用图，则应把检查重点换成手部接触和遮挡。
