# 完成一份单品宣传视觉：从需求简报到结果修正

2026-10-12 当前方向：只卖 Skill，不卖课。以下六篇原文作为免费系统学习采用；新 Course 修订 3、六个 lesson@3 与 catalog@3 提供完整匿名正文。下方草稿/拟试看描述保留首次作者记录，已经不是当前售卖或正文开放条件。原 index 快照保存在既有私有 delivery，原 authoring-manifest 不重写。

这门课带你把一句模糊要求变成可执行的视觉任务，再把真实结果中的问题变成下一轮具体修改。贯穿练习使用作者设定的无品牌饮品杯文字资料。你也可以换成自己的单品，但要重新整理该商品的事实。

完成六课后，你会交付一份需求简报、商品事实表、完整图像提示词、结果检查表、完整修订提示词和交接记录。文字练习可以直接完成；有实际图像结果时，再完成图像检查与迭代。课中的杯子改稿示例是文字模拟，六个教学样本的检查记录来自已有结果，二者分别标明。

适合已经能与 AI 助手对话、希望做单品静态宣传图的读者。准备一个文本编辑器、当前商品资料和你自己选择的图像工具。需要安装已发布方法时，先按[安装固定发布包](../../learning/install-fixed-package.md)操作；本课不要求更换工具或购买服务。
