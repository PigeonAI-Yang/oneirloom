# 04 写出完整提示词并提交一轮

这一课把已经选定的构图写成完整的图像提示词。任务说明告诉助手怎样协作；图像提示词描述画面里应出现什么。分开两者，会让提交与改稿更清楚。

## 从构图说明到图像提示词

先检查构图有没有覆盖商品、环境、机位、光线和比例。再把来源确认的商品特征写进去。不要把“请先问我需求”“读取某个技能”或“检查证据来源”放进图像提示词，这些是协作任务。

下面是贯穿杯子文字练习的完整提示词。它是作者编写的示范，没有对应的新生成结果。

```text
4:5竖幅的暖中性色调静物商品摄影。一只直立的奶油白色外带饮品杯位于浅木色台面中央，杯口配一只贴合杯口并保持闭合的白色杯盖，杯身套着浅灰色空白杯套。杯子完整入镜，杯盖上方和杯底下方留有清楚的画面空间。

镜头正对杯身中部，略高于杯身中线。背景为简洁的浅米白色，通过柔和明暗差让杯身轮廓与背景分开。柔和主光从画面左侧照入，沿杯壁形成宽阔柔和的亮区；杯底与台面接触，柔和接触阴影贴合支撑位置。杯身基色保持奶油白，白色杯盖和浅灰色杯套清楚可见。画面重点集中在杯子的完整外形与部件关系。
```

这段文字没有添加饮品内容、品牌、容量或材质。它也没有为了制造宣传感而追加未提供的标签文案。若当前任务要求准确品牌文字，先取得可读来源，再在适合的实际入口中处理。

## 一张图只承担一个视图

完整商品图与局部细节图最好分别交付。把“完整展示杯子”和“放大杯套纹理”同时塞进一张图，可能得到无意中的拼贴或过紧裁切。

本课先做全貌图。如果另做细节图，应单独写出完整提示词，并保留同一商品、基色、包装和光线方向。细节画面可以带上一段杯壁边缘，让读者知道这仍是同一个杯子。细节是否值得做，由商品资料和本次用途决定。

## 提交时保存什么

把最终提交的文字存成独立文件，而不是只保留助手第一次返回的版本。再记录实际工具、入口、模型名称与可见设置；没有看到的设置写“未提供”。如果上传了素材，记录每份素材的别名与用途。

一次提交记录可以采用下面的顺序：任务简报文件、商品资料文件、完整提交提示词文件、实际入口与设置、结果文件、后续检查表。每次改稿使用一个新编号，保留旧版。图像工具若支持参考图或局部编辑，只记录你实际使用的操作，不把“上传图片”自动当作商品身份已经锁定。

你现在没有图像工具时，仍可完成本课的完整提示词和提交计划。结果栏留到执行后再填写；不要以作者示范文字代替实际运行记录。

## 练习与参考答案

把下面这句改成完整图像提示词：“按之前那张，只把背景换成浅绿，其他不动。”

参考答案应展开当前商品与构图，而不是保留“之前”这个引用：

```text
4:5竖幅的暖中性色调静物商品摄影。一只直立的奶油白色外带饮品杯完整放在浅木色台面中央，白色杯盖贴合杯口并闭合，杯身套着浅灰色空白杯套。镜头正对杯身中部，略高于杯身中线。背景为浅绿色，左侧柔光沿杯壁形成宽阔柔和的亮区，杯底的接触阴影贴合台面。杯身保持奶油白基色，完整轮廓、杯盖与杯套清楚可见。
```

## 本课完成条件

保存一份脱离聊天上下文也能读懂的完整提示词。检查其中是否混入助手任务、未确认的商品性能，或两个互相冲突的视图。若实际执行，保留原始提交与真实结果，再进入下一课。
