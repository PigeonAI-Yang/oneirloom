# 02 锁定商品事实，留下可改空间

这一课要解决的是连续改稿中的商品漂移。背景换了，杯盖却变了；光线更漂亮了，杯套却多了文字。要减少这种情况，先把必须保持的内容从可调整的表达中拆出来。

## 给每项事实一个来源

继续使用虚构杯子文字练习。这里的来源是练习提供的文字资料，不是图片观察。把输入整理为下面的表格。

| 类别 | 内容 | 后续怎样处理 |
| --- | --- | --- |
| 商品事实 | 一只杯子，直立，奶油白杯身 | 每轮保留数量、姿态和基色 |
| 商品事实 | 白色杯盖贴合杯口并闭合 | 改背景时仍保持闭合和贴合 |
| 商品事实 | 浅灰色空白杯套 | 不添加未提供的文字或标记 |
| 已确认场景 | 浅木色台面 | 本轮沿用；若要更换，明确提出 |
| 表达选择 | 4:5、浅米白背景、左侧柔光 | 可以在用户指定时调整 |
| 未知 | 品牌、内容物、容量、尺寸、材质 | 当前画面不靠这些信息推进 |

“杯盖闭合”没有说明杯盖是平顶还是圆顶。因此，后来看到圆顶杯盖时，不能仅凭个人偏好判为商品错误。只有原始资料确认了平顶形状，你才有依据要求恢复平顶。

## 商品照和风格图分工不同

如果你使用自己的商品，给素材起清楚的名字。例如，商品照 A 用来确认杯子外形、杯盖和杯套；风格图 B 用来参考背景明暗与光线。B 中的杯子不成为 A 的商品事实，B 中的品牌也不自动进入你的画面。

若两张商品照发生冲突，先记录冲突。比如 A 显示黑盖、C 显示白盖，当前任务到底卖哪一款？这是需要用户选择的问题。无需把已经清楚的杯身颜色、数量和用途也重新询问一遍。

文字看不清时，写“标签字样尚未确认”，而不是猜一段更适合宣传的文案。如果本次要求准确重现标签，就需要补一张可读的来源；背景和构图仍可先讨论。

## 换背景时，怎样保留当前任务

现在只把浅米白背景换成浅绿色。不要发一条孤立的“背景改绿”，应带上当前完整提示词或可确认的任务，再明确保留项。

```text
沿用当前杯子任务，只把浅米白背景改为浅绿色。保留一只直立奶油白杯子、贴合并闭合的白色杯盖、浅灰色空白杯套、浅木色台面、4:5竖幅、正对杯身中部并略高于杯身中线的机位，以及左侧柔光。请给完整的新提示词。
```

新背景可能在商品上产生轻微反射。这属于必要的受光联动，不能把杯身的奶油白基色直接改成绿色。区分基色与照明，会让“保留商品颜色”更明确。

## 练习与参考答案

某份资料只说“表面有细纹和宽阔柔和的亮区”。助手写出“环保再生纸包装，防水耐磨”。找出新增内容，并改成可见描述。

参考答案：环保、再生纸、防水和耐磨都没有来源支持。可以写“包装表面呈现细微纹理，左侧柔光形成宽阔、低反差的亮区”。这句话描述画面，没有补出物理性能。

再检查一次杯子表：这轮换背景，是否需要品牌、容量或材质？不需要。缺少它们不妨碍当前提示词；如果任务改为突出容量，才需要容量来源。

## 本课完成条件

为当前商品保存一份事实表。每项事实能追溯到文字资料或具体素材，表达选择单独列出，未知项没有被补成规格。再写一条只改变一个已指定维度的改稿请求。
