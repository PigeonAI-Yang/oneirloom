# 06 只改当前问题，完成交接

最后一课把检查结论转成完整改稿，并整理一份另一个人能继续使用的交接记录。每轮保留已确认内容，让改动与结果能够对应起来。

## 选择一个问题，说明必要联动

对手持杯子样本，问题是右手遮挡杯套正面。修改手指的位置会影响握持方式，因此手指、接触和支撑可以作为同一个问题一起处理。它并不授权你同时更换杯子、衣服、背景和机位。

对数字形态样本，问题是圆片看起来像外接部件。下一轮应描述膨出从主体下三分之一区域如何连续开始、曲面如何接回，而不是只删除接缝这个词。机制不清楚时，更多风格形容词通常无法解决它。

## 完整改稿示范

下面是文字模拟分支。新增练习资料明确确认了低矮平顶白色杯盖，实际提交提示词也明确写了平顶；模拟结果描述却是拱起圆顶。这个分支没有新生成图，本例只展示怎样依据已确认形状组织改稿。

先写给助手的修改请求：

```text
本轮只修正杯盖顶面。练习资料和已提交提示词确认低矮平顶白色杯盖，结果描述为拱起圆顶。请恢复低矮平顶，保持盖缘贴合杯口并闭合。保留一只奶油白杯子、浅灰色空白杯套、浅木台面、4:5竖幅、原有机位、浅米白背景和左侧柔光。请输出完整中文修订提示词。
```

再单独保存完整图像提示词：

```text
4:5竖幅的暖中性色调静物商品摄影。一只直立的奶油白色外带饮品杯完整放在浅木色台面中央，杯身套着浅灰色空白杯套。杯口配低矮平顶的白色杯盖，顶面平缓，盖缘贴合杯口并保持闭合。

镜头正对杯身中部并略高于杯身中线，杯盖上方和杯底下方留有清楚的画面空间。背景为浅米白色，通过柔和明暗差使杯身轮廓清楚。左侧柔光照亮杯壁、杯套和杯盖，杯底与台面接触，接触阴影贴合支撑位置。杯身保持奶油白基色，杯套正面保持浅灰色空白，画面重点是完整外形与部件关系。
```

这一版只用于平顶形状已经确认的任务。回到第一课的原始杯子练习时，顶面形状仍没有资料，不能把此分支新增的事实悄悄带回去。

## 下一轮如何比较

先检查这轮修正目标是否实现，再看已通过项有没有退步。如果平顶恢复了，但杯套突然出现文字，这轮仍需要继续处理。记录“杯盖通过，杯套新增文字未通过”，不要把总体结果只写成“成功”。

保留旧提示词、旧结果、新提示词和新结果。实际入口、模型或设置发生变化，也要记下来，否则你无法判断差异来自文字修改还是运行条件。完成一轮后，再决定是否继续；不要把还未检查的新图当成最终版。

## 交付给自己或另一位协作者

最终记录按下面顺序组织：当前目标与用途、商品资料及别名、事实表、已选构图、完整提交提示词、实际工具与设置、结果文件、检查表、完整修订提示词、当前版本与未解决项。

交接说明可以这样写：

“当前任务是杯子商品页首图，保留一只杯子、奶油白杯身、闭合白盖和灰色空白杯套。本轮只处理已确认的平顶形状。当前结果文件和检查表随记录提供；先检查盖顶是否恢复，再核对杯套是否新增文字。请从这份完整修订提示词继续，保持背景、机位和光线。”

它告诉接手者目前版本和下一动作，不需要对方重新猜整段聊天。若还有未解决项，在交接里逐项指出，不用把它们隐藏在“已完成”后面。

## 练习与参考答案

你只要求把背景换成浅绿，助手同时把杯套改成深蓝。写一条纠正请求。

参考答案：“本轮只改背景。请恢复原有浅灰色空白杯套，保留浅绿背景以及此前确认的杯身、白色闭合杯盖、数量、台面、机位和左侧柔光，并给完整提示词。”这条请求指出了多改的内容，也保留了这轮已经确认的背景选择。

## 课程结课作业

为一个单品交出六份连续材料：需求简报、事实表、构图说明、完整提示词、结果检查表和完整修订提示词。没有实际图像结果时，前四份照常完成；后两份使用明确标注的文字模拟练习，并在你的记录里留下实际执行后的检查位置。

自查时逐项问：商品事实有来源吗？表达选择是否可执行？提示词脱离聊天仍完整吗？结果判断有实际依据吗？修订只处理本轮问题及必要联动吗？接手者能从当前版本继续吗？六项都能回答，课程目标才被兑现。
