# Oneirloom 0.3.0-preview.1

Fixed preview containing 22 sibling skills. Adds craft construction, digital form and space conception, expands the ten-family visual directory, and includes six concrete product recipes. The inspected teaching samples include three passes, two partial failures and one failure; see [teaching observations](../../skills/oneirloom/references/teaching-observations.md).

The previous 0.2.0-preview.1 release remains available with its original 18 skills and unchanged checksum. Private brand identity sources, original teaching image archives and local private prompts are excluded from this package.

The publisher-built ZIP contains a SOURCE-MANIFEST.json with the exact file inventory, skill IDs, hashes and source fingerprint. Check SHA256SUMS.txt before installation and copy all 22 directories under skills/ as siblings into a fresh project's .agents/skills/.

Package validation and inventory checks do not establish new-session behavior or repeat image reproduction. The publication record is maintained separately after the actual release.
