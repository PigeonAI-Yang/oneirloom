# Oneirloom 0.3.0-preview 源码记录

> 记录日期：2026-10-11。状态：开发中的源码预览，尚无对应发布包。本记录说明源码变化与已有验证，不代表正式发布、安装或图像效果验收。

## 源码变化

- 源码共 22 个 Skill：原有 19 项，加上工艺构造、数字造型和空间构想三个方法。另有 14 个既有条目按各自职责作了不同程度的调整。
- 十类视觉目录用于可选检索：画面方向未定时可探索；感受尚未成形时转入梦织；明确媒介或已定方向直接进入所属方法。目录是检索结构，不代表已经导入外部风格库；具体内容按实际需求逐条编写。
- 新增材质响应、静帧布置和按需服饰搭配 references。拼豆配方迁入工艺构造，迁移记录保存了提示词、图像与 JSON 的保全核对；盲盒对比与角色服装表仍留在各自原有方法中。
- 设计边界进一步明确：外观指导不代表实体制造、可编辑三维资产、产品事实或视频能力。
- 新增 [AI 可调用的元数据维护工具](../../scripts/sync_project_metadata.py)，自动生成中英文 README、插件信息、技能目录、仓库简介与网站共用数据；源码版本与已发布安装包分别记录。使用方法见[维护说明](../MAINTENANCE.md)。

详细范围见[视觉能力扩展方案](../visual-capability-expansion-plan.md)，源文件变化见[实施记录](../../work/visual-families-20261010/implementation-0.3.0-preview.md)，文件迁移核对见[迁移记录](../../work/visual-families-20261010/migration-preservation-0.3.0-preview.json)。
