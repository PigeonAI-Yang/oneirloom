# 织梦师 0.2.0-preview.1 候选版

本次候选版提供 18 个免费技能，重点是让创作对话承接当前需求，并交付可以直接使用的完整提示词。`0.2.0-preview.1` 和 `v0.2.0-preview.1` 是建议版本与标签，尚待用户确认。候选包准备、测试结果、用户验收与公开发布分别记录；本文不表示已发布或已完成安装验收。

## 创作时会有什么变化

需求已经清楚时，直接完成当前任务。需求仍模糊时，只补充会影响方向的问题，再给出有区别的创意选择。确认了产品、语言、参考图分工或创意后，后续修改沿用这些条件。

修改背景、风格或一句画面文案时，保留其他仍有效的决定，重新交付完整提示词。用户明确否定旧方向时，替换那一部分创意，同时保留可靠的产品事实。提示词放在独立代码块中，说明、参考图操作和模型参数留在块外；默认中英双语，明确只要中文时遵循该要求。

产品外形、包装和已提供文字按证据保留。看不清的标签、未知配料或未经确认的功效，不会被补成事实。需要准确标签但缺少来源时，明确保留这一缺口，并继续不依赖标签的构图工作。已经约定的微缩世界和幻想场景仍可继续，未知事实清单不写成生图提示词中的一串禁令。

主入口和直接调用的方法技能共用同一份交互约定。请求 SVG、素材集、教程或规范时，按对应成品类型交付；规格说明不能代替实际文件。已有图片与提示词只需排卡时，保留原提示词，不额外改写内容。

公开包的提示词卡默认无品牌水印，保持上方三分之一图片、下方三分之二完整提示词的 3:4 布局。需要水印时，可显式传入用户授权的本地 PNG。私有织梦兽、独立签名和品牌源素材不随免费包分发，制作普通卡片也不依赖它们。已公开历史案例中的完整作品图属于另一类素材，保留其原始说明与证据边界。

## 固定版本与来源

候选文件名为 `oneirloom-0.2.0-preview.1.zip`，校验文件为 `SHA256SUMS.txt`。[预留下载地址](https://github.com/PigeonAI-Yang/oneirloom/releases/download/v0.2.0-preview.1/oneirloom-0.2.0-preview.1.zip)尚未发布。`main` 继续用于开发，不能代替固定版本安装包。安装入口见包内[安装说明](../INSTALL.md)。核心技能无需 Go；图片生成工具、模型服务和可选 Python 卡片渲染环境另行提供。

本次来源是基础提交 `f8059e1a8b512d3af0302f4212521a82cade964c` 加工作树修改。包内 `SOURCE-MANIFEST.json` 使用 schema version 2，记录包版本、18 个技能 ID、打包文件大小与 SHA-256，以及工作树来源、技能内容指纹和 LFS 解指针来源。不能声称这个基础提交或尚未创建的标签本身等于候选包内容。最终 ZIP 哈希和清单哈希以实际产物为准，目前不填写占位哈希。

构建包需要取得八个已知 LFS 对象的真实内容。GitHub 自动生成的源码 ZIP 可能仍是指针文件，不能替代已经检查的发布者构建包。包的入口是 `docs/INSTALL.md`，根目录宣传 README 和大型详情页不属于这个精简安装包。

完整资源包约为 105 MB，超过当前校验脚本对插件目录提交采用的 100 MB 上限。本轮采用 GitHub Release 完整安装包及项目技能安装路线，不宣称符合插件目录提交条件。最终字节数及校验值以实际候选包和验收报告为准。表情贴图方法可使用用户提供的角色参考；私有品牌样本和带品牌图像的工作表不随包提供。

## 升级和恢复

先备份当前已验证安装、用户修改、原包及其哈希，再按两个版本各自的技能清单替换。只处理属于此次 Oneirloom 安装的目录，保留其他技能。没有已验证备份时，明确记录“缺少回退基线”，不能把任意旧标签当作稳定回退版本。

现有 0.1.1 历史包含私有水印，不能作为公开回退包再分发。用户可恢复自己已保留的准确备份或已验证原包。恢复旧的 15 技能版本时，按清单移除仅属于候选版的目录，避免混装 18 与 15 个技能。完整操作见[升级与回退](../INSTALL.md#preserve-a-rollback-before-upgrading)。安装或恢复后开启新对话，核对实际读取路径并重试已有成功需求。

## 结果记录与确认

每个测试或案例保留实际输入、完整实际输出和结果文件，不用后来修订的提示词替换历史原文。记录至少包括：

- 请求模型、推理强度、实际观察到的响应模型、宿主及工具版本。
- 实际执行的 UTC 时间、输入文件和输出文件；旧记录没有时间时写 `unknown`，不按今天补填。
- 基础提交、含工作树修改的来源清单及其 SHA-256、技能集合版本、候选 ZIP SHA-256。
- 实际读取的技能路径、所执行检查、观察结果，以及未执行项和未知字段。

来源提交和请求模型各自只能证明对应字段，不能替代实际包内容或服务器模型身份。新证据与原记录分开保存。[模型证据](../model-evidence.md)中的历史核验日期也不代表本次重新联网验证。

供用户确认的交付是具体候选 ZIP、`SHA256SUMS.txt`、来源清单和实际验收报告。完成本地检查后，先确认版本、内容及剩余缺口；创建标签、公开上传或插件目录提交仍需对应发布授权。当前没有执行这些发布动作，也没有取得 OpenAI 插件目录批准。
