## 当前实现与实际缺口

现有账号、订单快照、幂等支付事件、微信 Native 与支付宝 PagePay 适配器可作为后续 Skill 交易的基础，但并未支持 Skill 商品合同。当前 `OfferVersion.productKind`、权益 scope 与受限内容闭包只接受历史 `membership|course`，不能直接增加一个枚举或把旧商品改名。现有成员正文读取不是 Skill 文件交付。

本次关闭新订单和 checkout，返回 `410 PRODUCT_SALES_CLOSED`；支付方式列表为空，旧课程/会员不返回可购买报价。历史订单读取、合法旧付款/退款通知处理与旧授权记录保持。新版接口或数据合同须明确 SkillVersion/Package 精确引用、许可、固定文件交付、付款后获取和退款规则，并按关键合同设计责任处理；该后续决策不阻挡六课免费发布或旧销售撤销。

当前生产 `site` Worker 的 secrets 名称列表为空；仅有既有 ACCOUNT_DB、ASSETS、GALLERY_LIKES 与两个 RESTRICTED 标识绑定。Google OIDC 与微信/支付宝启用所需字段确实尚未配置。实际只读回读及安全输入入口见[配置核对记录](member-resources/product-visual-iteration-workpack-candidate-20261012/sale-options.md#当前生产配置核对)。未进行真实登录、收款或交易。
